## Latex 기본

### Latex 개념

LaTeX는 **수식을 포함한 글을 보기 좋게 표현하기 위한 문서 조판 시스템**이다. 문서의 내용과 형식을 명령어 형태로 작성하면 이를 조판하여 보기 좋은 결과물로 만들어준다. 특히 수학 수식을 텍스트만으로 표현할 수 있다는 점 때문에 논문, 기술 문서, 수학·통계 문서 등에서 잘 사용할 수 있다. 예를 들어 (a+b)/c 는 다음과 같이 작성할 수 있다.  

- Latex (leɪtɛk/레이텍 또는 lɑːtɛk/라텍)  
- 수식이 포함된 구조적인 글쓰기에 적합한 문서 조판 프로그램  
- 도널드 커누스가 만든 TeX를 기반으로  
- 레슬리 램포트가 사용 편의를 위한 매크로를 추가해 1984년에 발표  
- 문서의 내용과 형식, 스타일을 분리해 텍스트파일에 명령어를 작성하고 TeX 엔진이 이를 조판된 결과물로 변환해주는 방식  

```plaintext
\frac{a+b}{c}
```

결과 :   

$\frac{a+b}{c}$

> **문서 조판 시스템**은 글, 수식, 표, 그림 등의 내용을 일정한 규칙에 따라 배치하고 꾸며서 **읽기 좋은 문서로 만들어 주는 도구**다.   


### 장점  

- 수식 작성 : 수식 작성이 편리하며, 일반 텍스트와 함께 한 줄에 작성하는 인라인도 가능  
- 고품질 출력 : 최종 출력물에서 높은 가독성과 일관된 품질 제공  
- 호환성 : Plain Text 기반이므로 운영체제나 전용 프로그램 버전에 상관 없음  

### 포스팅 내용  

- 자주 사용하는 표현들을 정리하였다.  
- `|기능|문법|결과|` 형식으로 표를 작성한다.  
- 표현법을 외우지 않고 이해해서 쓸 수 있도록 보조 설명 추가하였다.  
- 계속 추가 예정

### Latex 수식 작성 방법

LaTeX 수식은 크게 **인라인 수식**과 **블록 수식**으로 작성한다.

#### (1) 인라인 수식

일반 문장 안에 수식을 함께 작성할 때 사용한다. 예를 들어 하나의 문장 안에 Latex 문법을 사용하는 경우, 아래와 같이 쓸 수 있다.  

```plaintext
아인슈타인의 질량-에너지 등가식은 $E = mc^2$이다.
```

결과 :  

아인슈타인의 질량-에너지 등가식은 $E = mc^2$이다.

---

#### (2) 블록 수식

코드블럭처럼 본문과 수식을 분리하여 별도의 영역에 표시할 수도 있다.  

```plaintext
\[
E = mc^2
\]

또는

$$
E = mc^2
$$
```

결과:

$$
E = mc^2
$$

---


LaTeX 명령어는 일반적으로 `\`로 시작하고, 명령에 전달하는 내용은 `{}` 안에 작성한다.

```latex
\command{value}
```

여러 줄로 구성된 수식은 단순 블록 수식보다 `align`, `gather`, `multline` 등의 수식 환경을 사용하는 것이 적합하다.

복잡한 기능은 `\begin`과 `\end`를 이용한 **환경(environment)** 형태로 작성하기도 한다.

```latex
\begin{environment}
...
\end{environment}
```

### Latex 기본 문법

자주 사용되는 기본 문법은 다음과 같다.

| 기능 | 문법 | 결과 |
|---|---|---|
| 위첨자 | `x^2` | $x^2$ |
| 아래첨자 | `x_i` | $x_i$ |
| 여러 문자 위첨자 | `x^{10}` | $x^{10}$ |
| 여러 문자 아래첨자 | `X_{test}` | $X_{test}$ |
| 괄호 크기 자동 조절 | `\left( \frac{a}{b} \right)` | $\left( \frac{a}{b} \right)$ |
| 수식 내부 텍스트 | `\text{if}` | $\text{if}$ |
| 작은 공백 | `a\,b` | $a\,b$ |
| 큰 공백 | `a\quad b` | $a\quad b$ |
| 줄바꿈 | `\\` | 현재 환경에서 다음 행으로 이동 |
| 주석 | `% comment` | 출력되지 않음 |

위첨자와 아래첨자는 한 문자만 사용하는 경우 `{}`를 생략할 수 있지만, 여러 문자를 첨자로 사용하는 경우 `{}`로 묶어야 한다는 점을 반드시 명심해두자.  

```plaintext
x^2   ...   x^{10}
x_i   ...   x_{test}
```


`\left`, `\right`를 사용하면 내부 수식의 높이에 따라 괄호 크기가 자동으로 조절된다.

```latex
\left(
    \frac{a+b}{c+d}
\right)
```

$$
\left(
    \frac{a+b}{c+d}
\right)
$$

## Latex 문법

### 1. 관계 연산자

#### (1) 동치 관계

| 기능 | 문법 | 결과 |
|---|---|---|
| 같음 | `=` | $=$ |
| 같지 않음 | `\ne`, `\neq` | $\ne$, $\neq$ |
| 정의 | `\doteq` | $\doteq$ |
| 정의 | `\doteqdot` | $\doteqdot$ |
| 정의 표시 | `\overset{\text{def}}{=}` | $\overset{\text{def}}{=}$ |
| 유사 (유사하거나 특정 관계에서 동치) | `\sim` | $\sim$ |
| 유사하지 않음 | `\not\sim` | $\not\sim$ |
| 역방향 유사 | `\backsim` | $\backsim$ |
| 유사 또는 동치 | `\simeq` | $\simeq$ |
| 근사 (수치적으로 대략 같음) | `\approx` | $\approx$ |
| 근사 | `\approxeq` | $\approxeq$ |
| 비례 | `\propto` | $\propto$ |

> `\sim` 계열은 두 대상이 유사하거나 특정 관계에서 동치임을 나타내고, `\approx` 계열은 주로 **수치적으로 대략 같음**을 표현한다.

#### (2) 순서 관계

| 기능 | 문법 | 결과 |
|---|---|---|
| 작음 | `<` | $<$ |
| 큼 | `>` | $>$ |
| 작거나 같음 | `\le`, `\leq` | $\le$, $\leq$ |
| 크거나 같음 | `\ge`, `\geq` | $\ge$, $\geq$ |
| 매우 작음 | `\ll` | $\ll$ |
| 매우 큼 | `\gg` | $\gg$ |
| 선행 | `\prec` | $\prec$ |
| 후행 | `\succ` | $\succ$ |
| 선행 또는 같음 | `\preceq` | $\preceq$ |
| 후행 또는 같음 | `\succeq` | $\succeq$ |

### 2. 사칙 연산자

| 기능 | 문법 | 결과 |
|---|---|---|
| 덧셈 | `+` | $+$ |
| 뺄셈 | `-` | $-$ |
| 곱셈 | `\times` | $\times$ |
| 곱셈 | `\cdot` | $\cdot$ |
| 나눗셈 | `\div` | $\div$ |
| 플러스마이너스 | `\pm` | $\pm$ |
| 마이너스플러스 | `\mp` | $\mp$ |

곱셈은 목적에 따라 `\times`와 `\cdot`을 구분해서 사용한다. 보통 숫자간 곱은 `\times`로, 변수나 수식 사이의 곱은 `\cdot` 으로 표현하기도 한다.  

```latex
3 \times 4\\
a \cdot b
```

$$
\begin{align*}
3 \times 4\\
a \cdot b
\end{align*}
$$

### 3. 분수 표현

| 기능 | 문법 | 결과 |
|---|---|---|
| 기본 분수 | `\frac{a}{b}` | $\frac{a}{b}$ |
| 텍스트 크기 분수 | `\tfrac{a}{b}` | $\tfrac{a}{b}$ |
| 디스플레이 크기 분수 | `\dfrac{a}{b}` | $\dfrac{a}{b}$ |

일반적으로는 `\frac{분자}{분모}` 형태를 사용하며, 중첩해서 사용할 수도 있다.  

```plaintext
\frac{1}{1+\frac{1}{x}}
```

$$
\frac{1}{1+\frac{1}{x}}
$$

### 4. 집합 연산자

| 기능 | 문법 | 결과 |
|---|---|---|
| 공집합 | `\emptyset` | $\emptyset$ |
| 공집합 | `\varnothing` | $\varnothing$ |
| 원소 | `\in` | $\in$ |
| 원소가 아님 | `\notin` | $\notin$ |
| 역방향 원소 관계 | `\ni` | $\ni$ |
| 부분집합 | `\subset` | $\subset$ |
| 부분집합 또는 같음 | `\subseteq` | $\subseteq$ |
| 상위집합 | `\supset` | $\supset$ |
| 상위집합 또는 같음 | `\supseteq` | $\supseteq$ |
| 교집합 | `\cap` | $\cap$ |
| 합집합 | `\cup` | $\cup$ |
| 여러 집합의 교집합 | `\bigcap` | $\bigcap$ |
| 여러 집합의 합집합 | `\bigcup` | $\bigcup$ |
| 집합 차 | `\setminus` | $\setminus$ |

`in`과 `ni`는 방향이 서로 반대이다.

```plaintext
x \in A, \quad A \ni x
```

$$
x \in A, \quad A \ni x
$$

비슷하게, `subset` 과 `supset`은 방향이 반대이다.  

```plaintext
x \subset A, \quad A \supset x
```

$$
x \subset A, \quad A \supset x
$$

- 교집합 기호는 모자와 비슷하게 생겨서 `cap`이라는 명칭이 되었다.  
- 합집합 기호는 컵과 비슷하게 생겨서 `cup`이라는 명칭이 되었다.  
- 부분집합에서 subset은 `sub set`, supset은 `super set`을 의미한다.

### 5. 대형 연산자

| 기능 | 문법 | 결과 |
|---|---|---|
| 합계 | `\sum` | $\sum$ |
| 곱 | `\prod` | $\prod$ |
| 코프로덕트 | `\coprod` | $\coprod$ |
| 적분 | `\int` | $\int$ |
| 이중 적분 | `\iint` | $\iint$ |
| 삼중 적분 | `\iiint` | $\iiint$ |
| 폐곡선 적분 | `\oint` | $\oint$ |
| 집합 합집합 | `\bigcup` | $\bigcup$ |
| 집합 교집합 | `\bigcap` | $\bigcap$ |

대형 연산자는 아래첨자와 위첨자를 이용하여 연산 범위를 함께 표현하는 경우가 많다.

```latex
\sum_{i=1}^{n} x_i
```

$$
\sum_{i=1}^{n} x_i
$$

적분 역시 같은 방식으로 범위를 표현할 수 있다.

```latex
\int_{0}^{1} x^2\,dx
```

$$
\int_{0}^{1} x^2\,dx
$$

### 6. 제곱, 제곱근, 거듭제곱근

| 기능 | 문법 | 결과 |
|---|---|---|
| 제곱 | `x^2` | $x^2$ |
| n제곱 | `x^n` | $x^n$ |
| 여러 문자 지수 | `x^{n+1}` | $x^{n+1}$ |
| 제곱근 | `\sqrt{x}` | $\sqrt{x}$ |
| n제곱근 | `\sqrt[n]{x}` | $\sqrt[n]{x}$ |
| 세제곱근 | `\sqrt[3]{x}` | $\sqrt[3]{x}$ |

거듭제곱은 `^`를 사용한다.

```latex
x^{n+1}
```

$$
x^{n+1}
$$

거듭제곱근은 `\sqrt[]`의 대괄호 안에 차수를 지정한다.

```latex
\sqrt[3]{8} = 2
```

$$
\sqrt[3]{8} = 2
$$

### 7. 상한과 하한

| 기능 | 문법 | 결과 |
|---|---|---|
| 최댓값 | `\max` | $\max$ |
| 최솟값 | `\min` | $\min$ |
| 상한 | `\sup` | $\sup$ |
| 하한 | `\inf` | $\inf$ |
| 극한 | `\lim` | $\lim$ |
| 상극한 | `\limsup` | $\limsup$ |
| 하극한 | `\liminf` | $\liminf$ |
| 무한대 | `\infty` | $\infty$ |

상한과 하한은 각각 `supremum`, `infimum`에서 이름을 가져온 `\sup`, `\inf`를 사용한다.

```latex
\sup_{x \in A} f(x)
```

$$
\sup_{x \in A} f(x)
$$

극한에서는 아래첨자를 이용해 접근 조건을 표현한다.

```latex
\lim_{x \to 0} \frac{\sin x}{x} = 1
```

$$
\lim_{x \to 0} \frac{\sin x}{x} = 1
$$

### 8. 논리학

| 기능 | 문법 | 결과 |
|---|---|---|
| 논리곱 AND | `\land` | $\land$ |
| 논리합 OR | `\lor` | $\lor$ |
| 부정 NOT | `\neg` | $\neg$ |
| 함의 | `\implies` | $\implies$ |
| 역함의 | `\impliedby` | $\impliedby$ |
| 동치 | `\iff` | $\iff$ |
| 모든 | `\forall` | $\forall$ |
| 존재 | `\exists` | $\exists$ |
| 존재하지 않음 | `\nexists` | $\nexists$ |
| 참 | `\top` | $\top$ |
| 거짓 | `\bot` | $\bot$ |
| 따라서 | `\therefore` | $\therefore$ |
| 왜냐하면 | `\because` | $\because$ |

논리식은 관계 연산자와 함께 사용하는 경우가 많다.

```latex
x > 0 \implies x^2 > 0
```

$$
x > 0 \implies x^2 > 0
$$

전칭 기호 `\forall`과 존재 기호 `\exists`도 다음처럼 사용할 수 있다.

```latex
\forall x \in \mathbb{R}, \quad x^2 \ge 0
```

$$
\forall x \in \mathbb{R}, \quad x^2 \ge 0
$$

```latex
\exists x \in \mathbb{R}
```

$$
\exists x \in \mathbb{R}
$$

## 기타  

### `align` 정렬

`align`에서는 `&`로 정렬 지점을 지정(앵커)할 수 있다.  

#### (1) 오른쪽 정렬

```plaintext
\begin{align*}
a + f = b + c + d + e & \\
x = y + z &
\end{align*}
```

$$
\begin{align*}
a + f = b + c + d + e & \\
x = y + z &
\end{align*}
$$


#### (2) 특정 위치 정렬

```plaintext
\begin{align*}
a + f &= b + c + d + e \\
x &= y + z
\end{align*}
```

$$
\begin{align*}
a + f &= b + c + d + e \\
x &= y + z
\end{align*}
$$

#### (3) 왼쪽 정렬

```plaintext
\begin{align*}
& a + f = b + c + d + e \\
& x = y + z
\end{align*}
```

$$
\begin{align*}
& a + f = b + c + d + e \\
& x = y + z
\end{align*}
$$
